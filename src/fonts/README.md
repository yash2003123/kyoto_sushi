# Fonts

Subsets of two Japanese type families, generated by `scripts/subset-fonts.py`
from the originals at [github.com/google/fonts](https://github.com/google/fonts):

- **Zen Old Mincho** (display) — weights 400, 700, 900
- **Zen Kaku Gothic New** (body and UI) — weights 400, 500, 700

Both are licensed under the SIL Open Font License 1.1; see `OFL.txt`. The
subsets are derived works and carry the same licence.

Each file contains Latin-1, Latin Extended-A, the typographic punctuation the
copy uses, and the twelve Japanese characters that appear on the site
(おみ丼京司寿得温物菜都飲). Adding Japanese copy without regenerating these
files will fall back to a system face for the new glyphs.
